# 🎬 Netflix Clone (React)

This project is a Netflix clone website built with React.
It mimics the design and behavior of Netflix, featuring an interactive UI and responsive web design that adapts to all screen sizes.

# 🚀 Main Features

👆 Show/Hide Descriptions on Click –
Implemented using useState with a key-value structure. The hidden description toggles on or off.

📱 Responsive Layout –
Fully optimized for desktop, tablet, and mobile devices.

# 🛠 Tech Stack

React (with Hooks: useState) , HTML, CSS
